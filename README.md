# Simple Interest Calculator

## Project Description

The Simple Interest Calculator is a basic project that calculates simple interest based on the principal amount, rate of interest, and time period.

## Formula

Simple Interest = (P × R × T) / 100

Where:

- P = Principal amount
- R = Rate of interest
- T = Time period

## Features

- Calculates simple interest
- Easy to use
- Simple and beginner-friendly
- Provides accurate results

## Example

If:

- Principal = ₹10,000
- Rate = 5%
- Time = 2 years

Then:

Simple Interest = (10000 × 5 × 2) / 100

Simple Interest = ₹1,000

## Technologies Used

- Basic programming concepts
- Arithmetic operations

## Purpose

This project demonstrates the implementation of a simple interest calculation using a basic programming approach.
